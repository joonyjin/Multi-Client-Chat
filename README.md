
Multi-Client Chat System

Tech Stack: Python · Linux · TCP Socket · Pytest · Jira · GitHub

Project Purpose

To develop a TCP-based chat system enabling real-time communication between a Linux server and multiple terminal clients, while conducting comprehensive functional, integration, performance, and stability testing.

Environment & Tools

• Programming Language: Python
• Server Environment: Linux
• Client: Terminal (CLI)
• Communication Protocol: TCP Socket
• Testing Framework: Pytest
• Project Management: Jira

Final Objectives

• Build a Linux-based chat server
• Support concurrent connections from multiple clients
• Implement message transmission and connection management
• Establish an automated testing environment
• Manage defect reporting and bug-fix histories
• Conduct performance testing and write the final QA report
